# CueTV releases

Downloads for the CueTV apps (APK files for Android TV and Google TV). There is no source code in this repository.

| App | What it is | Latest download |
|---|---|---|
| **CueTV+** | Everything: the home screen and live TV | [CueTVplus.apk](https://github.com/hprades/CueTV_releases/releases/download/v2.4.0-beta.96/CueTVplus.apk) |
| **CueTV** | Only the home screen | [CueTV.apk](https://github.com/hprades/CueTV_releases/releases/download/cuetv-v2.2.0-beta.70/CueTV.apk) |
| **TVHub** | Only live TV | [TVHub.apk](https://github.com/hprades/CueTV_releases/releases/download/tvhub-v2.4.0-beta.96/TVHub.apk) |

The apps update themselves from here (Settings > General > Check for updates). You can install more than one;
to move your data from one to another use Copy and transfer > Bring data from another app.

# Descargas de CueTV

Descargas de las apps CueTV (archivos APK para Android TV y Google TV). Este repositorio no contiene código.

- **CueTV+** (todo: pantalla de inicio y tele en directo): [CueTVplus.apk](https://github.com/hprades/CueTV_releases/releases/download/v2.4.0-beta.96/CueTVplus.apk)
- **CueTV** (solo la pantalla de inicio): [CueTV.apk](https://github.com/hprades/CueTV_releases/releases/download/cuetv-v2.2.0-beta.70/CueTV.apk)
- **TVHub** (solo la tele en directo): [TVHub.apk](https://github.com/hprades/CueTV_releases/releases/download/tvhub-v2.4.0-beta.96/TVHub.apk)

Las apps se actualizan solas desde aquí (Ajustes > General > Buscar actualizaciones). Puedes instalar varias; para
pasar tus datos de una a otra usa Copia y traslado > Traer datos de otra app.
